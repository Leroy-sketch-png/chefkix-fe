# Q116 Creator Preview Command Plan

## Goal

Make the existing no-write cooking simulation read like a finished creator tool
across manual creation, AI-assisted creation, and published-recipe management.

## Order

1. Verify every command enters the same store and panel lifecycle.
2. Replace QA-facing language and Rocket icons with one preview vocabulary and
   Play icon.
3. Consolidate only keys proven to share the consumed namespace.
4. Preserve the preview banner's no-XP/no-progress disclosure.
5. Rinse production source, then run focused and application gates.

## Risks

- Deleting a similarly named key from a different namespace.
- Renaming legitimate test actions unrelated to creator preview.
- Changing copy while accidentally breaking command wiring or keyboard focus.
