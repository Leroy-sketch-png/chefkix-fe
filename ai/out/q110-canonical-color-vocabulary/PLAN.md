# Q110 Canonical Color Utility Vocabulary

## Goal

Remove the remaining dead color utility vocabulary and the unique fixed-light/theme-flipping foreground pair without changing valid semantic APIs or palette values.

## Files

1. Recipe, Year in Cooking, Taste, Learning Narrative, and Taste Compatibility callers - normalize `gaming-*` to canonical XP/streak/level utilities.
2. Collections and User Profile - map undefined pink utilities to combo and stabilize the on-photo type pill.
3. Design-token contract - prevent invalid aliases and fixed-white/theme-text combinations from recurring.
4. Root governance and this evidence directory - retain decision and verification provenance.

## Order

1. Enumerate every invalid utility and disconfirm valid `pink` semantic APIs.
2. Normalize call sites and fix the unique contrast pair.
3. Add a global production-source guard.
4. Run focused, static, full-suite, build, compiled-CSS, Agent OS, and diff verification.

## Risks

1. Blind replacement changes the valid PageHeader `pink` API.
2. One dynamic or reordered invalid class evades the source guard.
3. The on-photo pill treatment loses contrast against an unusual cover image.
